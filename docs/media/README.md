# Presentation assets

Captured from the running local REFUGE application on 1 November 2026.
The interface is English; Wikipedia archives retain their actual languages.
The home page uses the application's marked demonstration household.
No assistant conversations, personal maps, precise GPS locations or secrets
are shown.

- refuge-home-en.png: home and first-aid shortcuts.
- refuge-equipment-en.png: essential equipment with cached product photographs.
- refuge-wiki-en.png: installed Wikipedia archive selection.
- refuge-overview-en.mp4: approximately 13 seconds, silent H.264 slideshow of
  these screenshots. This is a visual overview, not an inference benchmark
  or a claim that emergency scenarios were tested.

The equipment view includes contextual photographs from the linked Amazon.de
listings. Product photography and trademarks remain the property of their
respective owners. Source URLs and observation dates are in
../../content/equipment.images.json. The standalone photo cache is not tracked.
See ../public-release.md for the remaining publication review.
