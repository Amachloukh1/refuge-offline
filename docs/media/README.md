# Presentation assets

Captured from the running local REFUGE application on 1 November 2026.
The interface is English; Wikipedia archives retain their actual languages.
The home page uses the application's marked demonstration household.
No assistant conversations, personal maps, precise GPS locations or secrets
are shown.

- refuge-home-en.jpg: current home and first-aid shortcuts.
- refuge-emergency-en.jpg: immediate guidance and emergency contacts.
- refuge-readiness-en.jpg: manually confirmed household checklist.
- refuge-inventory-en.jpg: illustrated supplies and water planning.
- refuge-library-en.jpg: practical guidance and local illustrations.
- refuge-books-en.jpg: installed English books, filters and library header.
- refuge-book-covers-en.jpg: actual titles/authors with genre illustrations.
- refuge-hazards-en.jpg: illustrated disaster scenarios.
- refuge-health-en.jpg: emergency numbers and first-aid cards.
- refuge-equipment-en.png: illustrated equipment preparation.
- refuge-pharmacy-en.png: symptom/medicine example cards with generated illustrations.
- refuge-wiki-en.png: installed Wikipedia archive selection.
- refuge-overview-en.mp4: approximately 24-second, silent H.264 slideshow of
  the eight current English page screenshots at 1280 × 890. This is a visual overview, not an inference benchmark
  or a claim that emergency scenarios were tested.

The latest desktop screenshots use a 1440 × 1000 browser viewport (the captured
content width can exclude the scrollbar). They are JPEG files. The older PNG
equipment, pharmacy and Wikipedia screenshots remain as additional views.
The original home PNG is retained as a historical asset; the README uses
the current JPEG. The Books view is filtered to actual English-language
files; the interface does not translate the books themselves.

Page banners, genre artwork and pharmacy illustrations are generated
editorial assets supplied in `public/illustrations/`. They are copied to
`dist/illustrations/` during installation/build and work offline. See
../generated-page-illustrations.json and ../generated-illustrations.json
for prompts and asset paths. Screenshots document a prepared installation;
the displayed counts are not bundled content entitlements.

The equipment view includes contextual photographs from the linked Amazon.de
listings. Product photography and trademarks remain the property of their
respective owners. Source URLs and observation dates are in
../../content/equipment.images.json. The standalone photo cache is not tracked.
See ../public-release.md for the remaining publication review.
