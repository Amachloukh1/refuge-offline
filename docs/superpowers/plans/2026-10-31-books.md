# Books Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a multilingual offline book library, large searchable catalogue and explicit batch downloads inside REFUGE.

**Architecture:** Static source metadata separate from installed UTF-8 texts and their SHA-256 receipts. A confined server module supplies paginated search and one bounded cancellable queue; React renders text as text, never publisher HTML.

**Tech Stack:** Existing React/Vite/Node, filesystem and fetch; no external reading service.

**Spec:** docs/books-design.md, approved by user.

## Global Constraints
Four languages including Arabic; no automatic bulk download on startup; independent installed/catalogue states; no arbitrary URL/path supplied by clients; preserve original source and rights attribution; downloaded books excluded from Git.

## Review Focus
Interrupted downloads must not appear installed; unknown rights remain unavailable for automatic redistribution; RTL reading follows book language; a missing source does not erase installed texts; cancelled queues stop before the next item.
